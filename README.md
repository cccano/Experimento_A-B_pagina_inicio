# Experimento_A-B_pagina_inicio
Se realizan pruebas de hipótesis estádisticas para determinar si la nueva página de inicio presenta una diferencia significativa en la conversión de usuarios respecto a la página no actualizada.

## Objetivo 
Determinar si se debe implementar la nueva página de inicio o mantener la original de acuerdo a las pruebas realizadas.

**Datasets Utilizados**
- landing_experiment.csv : id de usuario, landing, región, dispositivo, fuente de tráfico, tipo de usuario, conversión y gasto.

**Etapas de Análisis**

🔍 Explorar y validar los datos.

💰 Comparar el gasto promedio por usuario entre la página A y B.

🎯 Comparar la tasa de conversión entre la página A y B.

🌐 Revisar la relación entre la fuente de tráfico y la conversión.

👤 Revisar la relación entre el tipo de usuario y la conversión.

📈 Visualización de los resultados.
